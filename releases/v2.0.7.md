# ARTIQ V2 2.0.7 — Ubuntu installer

For Ubuntu x86_64 PCs. Install the .deb package using your package manager. Existing local data stays in each user's home directory when upgrading.

- eMTTS opens in a new tab in the existing ARTIQ browser window.
- A fully completed delivery displays Completed in history even if its underlying run was cancelled after completion.
